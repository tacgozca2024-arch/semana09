# 🚀 Hackathon JavaScript - Semana 9

## 📌 Descripción

Este proyecto contiene la resolución de distintos ejercicios enfocados en el uso de JavaScript moderno (ES6+), trabajando con arreglos, objetos, estructuras de control y lógica de programación.

## 🌐 Demo del proyecto

🚀 Puedes verlo aquí: [Ver proyecto en vivo](https://tuproyecto.com)

## 🎯 Objetivo

Aplicar los conocimientos adquiridos durante el módulo para resolver problemas utilizando buenas prácticas y métodos actuales de JavaScript.

## 🛠️ Tecnologías usadas

* HTML5
* CSS3
* JavaScript (ES6+)

## 📂 Contenido

* Ejercicios con arrays y objetos
* Uso de estructuras de control
* Lógica de programación aplicada

## ▶️ Ejecución

1. Abrir el archivo `index.html` en el navegador
2. Revisar la consola para visualizar los resultados
